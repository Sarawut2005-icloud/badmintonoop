## 4. Interface — `Billable` ⏱ 2:45–3:45
🖥 `model/Billable.java` แล้วตามด้วย `Club.revenue()`

```java
public interface Billable extends Serializable {
    LocalDate paidOn();
    RevenueType type();
    double amount();
}
```

🗣 "อะไรก็ตามที่ทำให้สนามมีรายได้จะ implement interface นี้ คือการจองสนาม การซื้อแพกเกจ และการเช่าหรือขายอุปกรณ์
ตอนทำรายงานรายได้ ผมวนลูปเดียวผ่าน `List<Billable>` เรียก `amount()` ได้เลย โดยไม่ต้องรู้ว่าแต่ละรายการเป็นคลาสอะไร นี่คือ **polymorphism** ครับ
ถ้าวันหน้ามีรายได้ประเภทใหม่ เช่น ค่าเรียนแบด ก็แค่ให้คลาสใหม่ implement `Billable` หน้ารายงานไม่ต้องแก้สักบรรทัด"

## 5. Abstract class — `User` และ `Page` ⏱ 3:45–4:45
🖥 `model/User.java`, `Cashier.java`, `ui/MainView.java`

```java
public abstract class User {
    public abstract String roleName();
    public abstract List<Menu> menus();
}
```

🗣 "`User` เป็น abstract class มีลูกสองตัวคือ `Cashier` กับ `Admin` แต่ละบทบาทบอกเองว่าใช้เมนูอะไรได้
หน้าหลักจึงแค่สร้างปุ่มจาก `user.menus()` ทั้งโปรแกรม**ไม่มี if-else เช็กสิทธิ์**สักที่เลยครับ
อีกตัวคือ `Page` ซึ่งเป็น abstract class ของหน้าจอทุกหน้า ทุกหน้าต้องมีเมธอด `refresh()` พอผู้ใช้สลับเมนู หน้าหลักก็เรียก `page.refresh()` ได้โดยไม่ต้องรู้ว่าเป็นหน้าไหน"

## 6. หัวใจของระบบ — การคิดราคา ⏱ 4:45–5:45

```java
int fromPackage = Math.min(hours, member.packageHours());
for (int h = 1; h <= hours - fromPackage; h++) {
    if ((member.paidHours() + h) % LOYALTY_EVERY == 0) discounted++;
}
```

🗣 "ระบบใช้ชั่วโมงแพกเกจก่อน ส่วนที่เหลือจ่ายเงินสด ระหว่างนั้นนับสะสมไปทีละชั่วโมง ชั่วโมงไหนลำดับหาร 20 ลงตัว คือชั่วโมงที่ 20, 40, 60 จะคิดแค่ 54 บาท ซึ่งเท่ากับ 30 เปอร์เซ็นต์ของ 180
ผลลัพธ์ออกมาเป็น `Quote` ที่บอกได้ว่ากี่ชั่วโมงหักจากแพกเกจ กี่ชั่วโมงราคาเต็ม และกี่ชั่วโมงได้ส่วนลด หน้าจอจึงแสดงรายละเอียดราคาได้ทันทีก่อนกดยืนยัน

## ❓ เตรียมตอบคำถาม

| คำถามที่อาจโดนถาม | คำตอบสั้น ๆ |
|---|---|
| interface ต่างกับ abstract class ยังไง | interface บอกแค่ว่า**ทำอะไรได้** (Billable = มีรายได้) และคลาสไหนก็ implement ได้ ส่วน abstract class เก็บ**ของที่ใช้ร่วมกัน** เช่น username/password ของ User และบังคับให้ลูกเขียนส่วนที่ต่างกัน |
| polymorphism อยู่ตรงไหน | `user.menus()`, `page.refresh()` และ `billable.amount()` เรียกเหมือนกันแต่ทำงานต่างกันตามชนิดจริง |
| ทำไมไม่ใช้ฐานข้อมูล | โจทย์ไม่ได้กำหนด ผมใช้ Java Serialization บันทึกลงไฟล์ โดยเขียนไฟล์ชั่วคราวก่อนแล้วค่อยแทนที่ ไฟล์จริงจึงไม่เสียถ้าไฟดับกลางคัน |
| ทำไมจองด้วยแพกเกจไม่ต้องแนบสลิป | ยอดเป็น 0 บาท ไม่มีการโอนเงิน สลิปจึงไม่มีความหมาย (ถ้าอาจารย์ต้องการให้แนบทุกครั้ง แก้ได้ในบรรทัดเดียวใน `Club.book`) |
| ชั่วโมงที่ 40 ได้ลดไหม | ได้ครับ ระบบคิดทุกชั่วโมงเงินสดที่ 20, 40, 60, … |
| ถ้าจองคร่อมเวลาปิดล่ะ | `Club.book` ตรวจว่า `start + hours <= closeHour(date)` ไม่ผ่านก็จองไม่ได้ |
| วันหยุดนักขัตฤกษ์รู้ได้ยังไง | `ClubRules` มีทั้งวันหยุดที่ตรงวันเดิมทุกปี และวันหยุดตามจันทรคติกับวันหยุดชดเชยปี 2569 |
